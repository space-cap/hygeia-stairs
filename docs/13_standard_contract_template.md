# 13. 현장 즉시 체결용 1장 표준 계약서 & 견적서 템플릿

> **대면 현장에서 3분 만에 서명받는 A4 1장 표준 계약서**
> 임대인이나 관리단 대표와 현장에서 구두 합의가 되었을 때, 곧바로 꺼내어 작성하고 서로 1부씩 나누어 가질 수 있는 법적 효력을 갖춘 표준 서식입니다.

---

## 1. 정기 건물관리(계단청소) 표준계약서 (인쇄용 전문)

```
                       건 물 관 리 (계 단 청 소) 표 준 계 약 서
                       ─────────────────────────────────────────

 [의뢰인 (갑)]
   - 성 명(상호): _______________________    - 생년월일(사업자번호): ____________________
   - 연 락 처: __________________________    - 주 소: _________________________________

 [관리사업자 (을)]
   - 상 호: 하이지아 (Hygeia)                 - 대 표 자: _______________________________
   - 사업자등록번호: ____________________    - 연 락 처: _______________________________
   - 주 소: 서울특별시 강남구 대치동

 위 당사자는 아래 관리 대상 건물에 대한 정기 청소 및 환경관리 위탁 계약을 다음과 같이 체결한다.

 1. 관리 대상물
   - 건 물 명: __________________________    - 소 재 지: _________________________________
   - 규 모: 지상 ____층 / 지하 ____층 (총 ____세대 / 점포)   - 엘리베이터: [  ] 유  [  ] 무

 2. 계약 기간 및 작업 일정
   - 계약 기간: 202___년 ___월 ___일 ~ 202___년 ___월 ___일 (1년 단위, 만료 1개월 전 이의 없을 시 자동 연장)
   - 방문 주기: [  ] 주 1회 (월 4회)    [  ] 주 2회 (월 8회)    [  ] 기타 (               )
   - 작업 요일: 매주 [      ]요일 (새벽 05:00 ~ 오전 07:30 사이 완료 원칙)

 3. 월 관리비 및 대금 지급
   - 월 관리비: 일금 ________________________ 원정 (￦ _______________ / 부가세 별도·포함)
   - 지급 방식: 매월 [      ]일 선불/후불 계좌 입금
   - 입금 계좌: ________________ 은행  ___________________________ (예금주: 하이지아)

 4. 청소 관리 범위
   ① 현관 로비: 공동현관 유리문 손자국·먼지 세정, 우편함 광고물 제거, 도어락 먼지 청소
   ② 계단 및 복도: 전 층 바닥 정전기 먼지 포집 및 친환경 중성 세정 마포 작업, 난간 손잡이 소독
   ③ 창틀 및 난간: 계단실 창틀 먼지 및 거미줄 제거
   ④ 엘리베이터(해당 시): 내부 바닥 세정, 벽면 및 조작 버튼 손자국 세정
   ⑤ 외부 공용부: 1층 주차장 바닥 쓰레기·담배꽁초 수거, 분리수거대 주변 정돈
   ※ 단, 대형 폐기물 스티커 부착 배출, 세대 내부 청소, 외벽 고소 작업은 본 계약 범위에서 제외한다.

 5. 안심 보고 및 품질 보증
   - '을'은 매회 청소 완료 후 작업 전/후 비교 사진을 '갑'의 이동전화(카카오톡/문자)로 전송하여 보고한다.
   - 청소 상태에 하자가 있을 경우 '갑'의 요청 시 24시간 이내에 무상으로 재청소를 실시한다.

 6. 손해배상 및 배상책임보험
   - '을'은 업무 수행 중 '을'의 명백한 과실로 시설물이 파손되거나 보행자 사고가 발생한 경우, '을'이 가입한
     영업배상책임보험(보상한도 1억 원)을 통해 즉시 원상복구 또는 배상 책임을 진다.

 7. 계약의 해지
   - 당사자 일방이 본 계약을 해지하고자 할 때에는 최소 30일 전에 상대방에게 통보하여야 하며, 별도의
     위약금 없이 정산 후 계약을 종료할 수 있다.

 8. 특약 사항
   ______________________________________________________________________________________________
   ______________________________________________________________________________________________

 본 계약의 성립을 증명하기 위하여 계약서 2부를 작성하고, '갑'과 '을'이 서명·날인 후 각 1부씩 보관한다.

                                                     202___년 _____월 _____일

                     [갑] 의 뢰 인 :                          (인 / 서명)
                     [을] 하이지아 :                          (인 / 서명)
```

## 2. 현장 맞춤 간이 견적서 템플릿 (계약 직전 교부용)

계약서 작성 전, 임대인이 *"얼마인지 종이로 한 장 줘보세요"*라고 할 때 건네는 견적서 서식입니다.

```
                              견    적    서
                              ───────────
   수 신: ________________ 님 귀하                 견 적 일: 202___년 ___월 ___일
   건물명: ________________ (대치동 소재)          공 급 자: 하이지아 (대표 직통: 010-XXXX-XXXX)

   아래와 같이 정기 계단 및 공용부 환경관리 견적을 제출합니다.

   ────────────────────────────────────────────────────────────
   품 명 / 관리 항목        주기 / 규격        월 견적 금액          비  고
   ────────────────────────────────────────────────────────────
   빌라 계단 및 공용부 관리  주 1회 (월 4회)     ￦ ___________ 원   카톡 전후 사진 보고 포함
   (현관, 계단, 복도, 창틀,                      (세대당 약 _____원)   분리수거대 정돈 포함
    주차장, 우편함 일체)     주 2회 (월 8회)     ￦ ___________ 원   호텔식 광택 세정 관리
   ────────────────────────────────────────────────────────────
   초기 묵은때 딥클린(선택)  1회 집중 케어       ￦ ___________ 원   정기 계약 시 50% 할인
   ────────────────────────────────────────────────────────────
   합 계 금 액 (월 기준) :  일금 ___________________________ 원정 (￦ ____________)
   ────────────────────────────────────────────────────────────
   * 특기사항: 영업배상책임보험(1억) 가입 업체 / 대치동 주민 대표 직접 관리
```

## 3. 현장 계약 체결 팁 (대표님 실전 요령)

1. **클립보드(받침대) 지참**: A4 계약서 2부와 볼펜 2자루를 검은색 가죽 클립보드에 끼워 들고 다니면 대단히 전문적으로 보입니다.
2. **도장 불필요 (서명으로 즉시 가능)**: 법적으로 본인 자필 서명만으로 계약 효력이 100% 발생합니다.
3. **"언제든 해지 가능" 조항 강조**: 제7조(30일 전 통보 시 위약금 없이 해지)를 짚어주며 *"마음에 안 드시면 언제든 말씀만 하시면 됩니다"*라고 안심시켜 계약 문턱을 낮춥니다.
4. **그 자리에서 스마트폰 번호 저장**: 카톡으로 사진을 받아보실 임대인의 스마트폰 번호를 계약서 작성 즉시 저장하고 테스트 톡을 보냅니다.
