# 29. 성원애드피아 / 오프린트미 실물 명함·전단지 1분 인쇄 발주 가이드

> **"자본금 300만 원 중 단 3만 원으로 실물 명함 500장 + 전단지 500장 완벽 확보"**  
> 인쇄소에 비싼 디자인비를 주지 않고, 이미 제작된 하이지아 웹 규격 인쇄본을 통해 초저가로 실물 인쇄물을 발주하는 실전 매뉴얼입니다.

## 2. 브라우저에서 인쇄용 고화질 PDF 추출 방법 (1분 컷)

별도의 일러스트레이터나 포토샵 없이, 크롬(Chrome) 또는 엣지(Edge) 브라우저에서 즉시 추출합니다.

### 1) 명함 인쇄 파일 추출 ([print/namecard.html](../print/namecard.html))
1. 브라우저에서 [`print/namecard.html`](../print/namecard.html) 열기
2. 키보드 `Ctrl + P` (인쇄 창 열기)
3. **설정값 필수 확인**:
   - **대상**: `PDF로 저장` 선택
   - **페이지**: `모두`
   - **레이아웃**: `가로` 또는 `세로` (화면 비율에 맞춤)
   - **설정 더보기** 클릭:
     - **용지 크기**: `A4`
     - **여백**: `없음` (None)
     - **배경 그래픽**: **반드시 [체크 ✔]** (배경색과 뱃지가 누락되지 않음)
4. `저장` 클릭 → 파일명을 `하이지아_명함_A4인쇄용.pdf`로 저장.

### 2) 전단지 인쇄 파일 추출 ([print/flier.html](../print/flier.html))
1. 브라우저에서 [`print/flier.html`](../print/flier.html) 열기
2. 키보드 `Ctrl + P`
3. 설정값:
   - **대상**: `PDF로 저장`
   - **레이아웃**: `세로`
   - **여백**: `없음`
   - **배경 그래픽**: **[체크 ✔]**
4. `저장` 클릭 → 파일명을 `하이지아_A4전단지_인쇄용.pdf`로 저장.

## 3. 성원애드피아 3분 발주 스텝 가이드

### 1) 명함 주문하기
1. **성원애드피아(swadpia.co.kr)** 접속 및 회원가입/로그인
2. 상단 메뉴 **[명함]** > **[일반명함]** 클릭
3. 주문 옵션 선택:
   - **품목**: 스노우 화이트 250g
   - **사이즈**: 재단사이즈 90 × 50 mm (작업사이즈 92 × 52 mm)
   - **인쇄도수**: 양면 칼라 8도
   - **코팅**: 양면 무광코팅
   - **수량**: 500매 (1건)
4. 하단 **[파일 업로드]**에 방금 저장한 PDF 첨부
5. 주문자 정보 및 배송지 입력 후 결제 완료!

### 2) A4 전단지 주문하기
1. 상단 메뉴 **[전단지]** > **[합판전단]** 클릭
2. 주문 옵션 선택:
   - **용지**: 아트지 100g (가장 대중적이고 매끄러운 전단지 용지)
   - **사이즈**: A4 (210 × 297 mm)
   - **인쇄도수**: 단면 칼라 4도
   - **수량**: 0.5연(500매) 또는 1연(1,000매)
3. **[파일 업로드]**에 전단지 PDF 첨부 후 결제 완료!

## 4. 인쇄 발주 시 3대 실수 방지 체크리스트

1. **배경 그래픽 누락 방지**:
   - PDF 저장 시 '배경 그래픽' 체크를 빼먹으면 틸 그린 색상이나 표 테두리가 하얗게 날아갑니다. 저장 후 PDF를 열어 색상이 다 채워져 있는지 5초간 확인하세요.
2. **글꼴 깨짐(아웃라인) 없음**:
   - 웹폰트(Pretendard)가 PDF에 벡터 형태로 자동 임베딩되므로 인쇄소에서 폰트 깨짐 경고 없이 그대로 출력됩니다.
3. **출고 및 배송 일정**:
   - 평일 오후 3시 이전에 발주하면 통상 익일 출고되어 **주문 후 2~3일 내에 자택으로 택배 도착**합니다.
   - 주말 임장 일정에 맞추려면 **수요일 오전까지 결제**하는 것이 안전합니다.

## 5. 수령 후 D-Day 현장 배치

택배 상자를 받으시면 즉시 아래와 같이 소분하여 가방에 세팅합니다:
- **명함 지갑**: 명함 20장 삽입 (구겨지지 않게 보관)
- **A4 클립보드**: 전단지 40장을 클립보드 뒤편에 정갈하게 끼움 (클립보드 앞면은 [field_crm.html](../print/field_crm.html) 장착)
- **여분 보관**: 나머지 명함 480장과 전단지 460장은 자택 서랍에 깔끔하게 보관하고, 매주 임장 나갈 때마다 30~40장씩 리필합니다.
