# 30. 카카오톡 비즈니스 채널 개설 & 자동 웰컴 메시지 세팅 가이드

> **"개인 카톡 대신 '하이지아 대치본점' 공식 채널로 신뢰도 300% 극대화"**  
> 카카오톡 채널 관리자센터 3분 개설, 자동 웰컴 카드 메시지 세팅, 자주 묻는 질문 챗봇 3종, 그리고 본업 중에도 고객을 놓치지 않는 자동 응답 매뉴얼입니다.

---

## 1. 카카오톡 비즈니스 채널을 써야 하는 3대 이유

1. **개인 카톡 프로필 노출 방지 & 직장인 겸업 안전**:
   - 대표님의 개인 카톡 프로필(가족 사진, 일상 사진)을 숨기고, **"하이지아 대치본점"이라는 신뢰감 있는 전문 브랜드 프로필**로 고객을 응대합니다.
2. **첫 접속 시 자동 웰컴 카드 발송**:
   - 고객이 카톡 링크를 누르는 즉시 자동으로 환영 인사와 함께 **`[1개 층 무료 시범 신청]` 버튼**이 발송되어 24시간 자동으로 문의를 수집합니다.
3. **직장 근무 시간(09:00~18:00) 안심 응대**:
   - 낮 시간에 본업 업무로 바로 답장을 못 하더라도, 자주 묻는 질문(FAQ) 자동응답 버튼이 고객의 궁금증을 1초 만에 해결해 줍니다.

---

## 2. 3분 만에 카카오톡 채널 개설하기

1. PC 또는 모바일 브라우저에서 **[카카오톡 채널 관리자센터(center-pf.kakao.com)](https://center-pf.kakao.com)** 접속
2. 기존 카카오 계정으로 로그인 후 **[+ 새 채널 만들기]** 클릭
3. **채널 프로필 정보 입력**:
   - **채널 이름**: `하이지아 대치본점` (또는 `하이지아 프리미엄 계단청소`)
   - **검색용 아이디**: `@hygeia_clean` (또는 `@하이지아대치`)
   - **카테고리**: `비즈니스` > `청소/세탁/방역`
   - **소개 메시지**: 
     > `대치동 거주 대표 직접 관리 | 무소음 새벽 정기케어 | 매회 카톡 4컷 전/후 사진 안심 보고 | 1억 영업배상책임보험`
   - **프로필 사진**: 틸 그린 방패 아이콘 또는 청결한 하이지아 로고 등록
4. **[확인]** 클릭 → 채널 개설 완료! (비용 0원)
5. 좌측 메뉴 **[관리]** > **[상세설정]**에서 **'채널 공개'**와 **'1:1 채팅'**을 모두 **[ON]**으로 켭니다.

## 3. 첫 진입 시 자동 발송되는 웰컴 메시지 세팅 (원고)

고객이 채널을 추가하거나 1:1 채팅방에 들어왔을 때 자동으로 즉시 전송되는 첫 메시지입니다.

- 설정 위치: **채널 관리자센터** > **[메시지]** > **[웰컴 메시지]**

### 1) 웰컴 메시지 본문
```text
안녕하세요! 대치동 프리미엄 정기 계단관리 [하이지아 대치본점]입니다. ✨

대치동 주민인 대표가 매주 직접 방문하여, 
5분 만에 훔치고 도망가는 유령 청소와 소음 민원 없는 프리미엄 청결을 약속드립니다.

🎁 [대치동 임대인 특전 혜택]
돈부터 내지 마세요! 
사장님 건물의 [1층 로비 + 계단 1개 층]을 비용 1원도 안 받고 무료로 반짝반짝 광택을 내드립니다. 
대표가 직접 닦아놓은 계단을 직접 눈으로 확인하시고 마음에 드실 때 계약하세요.

아래 버튼을 누르시면 무료 시범 청소를 바로 신청하실 수 있습니다. 👇
```

### 2) 웰컴 카드 버튼 3개 세팅
- **버튼 1**: `🚀 1개 층 무료 시범 신청`
  - 링크 타입: 웹사이트 링크
  - 연결 URL: `https://hygeia-stairs.vercel.app/#applyForm`
- **버튼 2**: `💰 투명한 표준 단가표 확인`
  - 링크 타입: 웹사이트 링크
  - 연결 URL: `https://hygeia-stairs.vercel.app/#pricing`
- **버튼 3**: `📞 대표 직통 전화 상담`
  - 링크 타입: 전화번호
  - 연결 번호: `010-XXXX-XXXX`

## 4. 자주 묻는 질문 (간편 채팅 FAQ 3종 세팅)

고객이 채팅창 하단 버튼을 누르면 1초 만에 자동 답변이 나가는 챗봇 기능입니다.

- 설정 위치: **[1:1 채팅]** > **[채팅방 커스텀 메뉴]** (또는 **[자주 쓰는 답변]**)

### Q1. 청소비는 얼마인가요? (단가 안내)
- **질문 버튼**: `💰 청소비는 얼마인가요?`
- **자동 답변 텍스트**:
```text
[하이지아 정직한 표준 단가표]
하청 용역 알바를 쓰지 않는 대표 직영 관리 기준입니다:

• 4층 빌라 (주거형): 월 70,000원 (회당 17,500원꼴 / 대치동 최다 선택)
• 5층 빌라 / 상가주택: 월 80,000원 (회당 20,000원꼴)
※ 주 1회 정기 방문 (월 4회 관리 / VAT 별도)

관리 범위:
• 1층 공동현관 유리 및 도어락 손지문 제거
• 전 층 대리석 계단 먼지 흡착
• 계단 손잡이 에탄올 무취 살균 소독
• 필로티 주차장 담배꽁초 수거
• 매회 완료 카톡 4컷 사진 안심 보고

지금 신청하시면 1개 층 무료 시범 청소를 먼저 받아보실 수 있습니다!
```

### Q2. 1개 층 무료 시범은 어떻게 신청하나요?
- **질문 버튼**: `🎁 1개 층 무료 시범 신청 방법`
- **자동 답변 텍스트**:
```text
비용 청구 0원! 부담 없이 신청하세요.
채팅창에 아래 3가지를 적어주시면 대표가 10분 내로 일정 확인 답장을 드립니다:

1. 건물 위치 (예: 대치4동 주민센터 인근 OOO빌라)
2. 건물 층수 (예: 4층, 엘리베이터 없음)
3. 대표자 연락처

약속된 날짜 새벽에 1층 로비와 계단 1개 층을 무료로 싹 닦아놓고 완료 카톡 사진을 전송해 드리겠습니다. 확인 후 마음에 안 드시면 정기계약을 안 하셔도 전혀 부담 없습니다!
```

### Q3. 새벽에 시끄럽지 않나요? (소음 민원 보증)
- **질문 버튼**: `🤫 새벽 청소 소음 민원 없나요?`
- **자동 답변 텍스트**:
```text
하이지아는 모터 진공청소기를 일체 사용하지 않는 "소음 0dB 무소음 건·반건식 청소"를 진행합니다.

독일산 극세사 평면 밀대로 미세먼지를 자석처럼 흡착하여 청소하므로, 수험생과 직장인이 잠든 새벽 5시에도 발소리 하나 없이 조용하게 청소를 마칩니다. 
소음 민원에 대해서는 하이지아가 100% 책임집니다!
```

## 5. 채널 고유 주소 확인 및 랜딩페이지 연결

1. 채널 관리자센터 홈 화면에서 **채널 홈 URL**을 확인합니다:
   - 예: `http://pf.kakao.com/_xxxx`
2. 이 URL을 고객 상담용 카톡 링크로 활용합니다:
   - 공식 웹사이트([`index.html`](../index.html)) 하단 고정 바 `[💬 카톡 1:1 상담]` 버튼에 해당 링크 연결
   - 당근마켓 비즈프로필 웹사이트 주소 또는 홍보 전단지 QR 코드에 삽입
3. 이제 대표님이 직장에서 근무 중일 때도 카카오톡 채널이 24시간 자동으로 고객에게 웰컴 카드를 보내고 무료 시범 신청을 접수받게 됩니다!
