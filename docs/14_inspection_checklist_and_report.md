# 14. 카톡 사진 보고 템플릿 & 현장 체크리스트

> **"하이지아의 가장 강력한 무기: 눈에 보이는 카카오톡 보고서"**
> 경쟁업체는 청소를 하고 그냥 떠나지만, 하이지아는 매회 청소 완료 후 사진과 함께 단정한 보고 문자를 보냅니다. 
> 임대인이 *"아, 오늘도 내 건물이 대치동에서 가장 깨끗하게 관리되고 있구나"*라는 안도감을 느끼게 만드는 실전 템플릿입니다.

---

## 1. 카카오톡 전송용 표준 보고 템플릿

스마트폰 메모장(또는 카카오톡 나와의 채팅방)에 복사해 두고, **건물명과 날짜만 바꾸어 사진 4장과 함께 묶음 전송**합니다.

### 템플릿 A: 정기 청소 완료 보고 (일반형)
```
[하이지아 정기 관리 보고서] 🌿

■ 관리 대상: {건물명} (대치동)
■ 관리 일시: 202X년 X월 X일(요일) 06:15 완료
■ 담당 관리자: 하이지아 대표 직접 시공

금일 {건물명} 정기 계단 및 공용부 관리를 정성껏 완료하였습니다.

[금일 주요 관리 내역]
1. 전 층 계단실/복도: 정전기 미세먼지 포집 및 친환경 중성 살균 세정
2. 현관 로비: 공동현관 유리문 손자국 제거 및 광택 케어
3. 부속 시설: 창틀 먼지, 계단 손잡이 난간 소독, 우편함 광고 스티커 제거
4. 외부 공용부: 1층 주차장 꽁초 수거 및 분리수거대 주변 정돈

깨끗해진 현장 사진 4장을 함께 첨부해 드립니다.
입주민분들이 쾌적하고 안전한 출근길이 되도록 늘 최선을 다하겠습니다.
감사합니다!

- 하이지아(Hygeia) 대치본점 드림 -
(문의/불편사항 접수: 010-XXXX-XXXX)
```

---

### 템플릿 B: 특이사항 발견 시 보고 (임대인이 감동하는 포인트!)
> 계단 청소 중 **센서등 고장, 불법 쓰레기 투기, 택배 방치, 누수 흔적**을 발견했을 때 전달하는 템플릿입니다. 임대인은 관리인이 없는 빌라에서 이런 정보를 알려주는 업체를 절대 해지하지 못합니다.

```
[하이지아 현장 특이사항 안내] 📢

{임대인/대표님}님, 안녕하세요! 하이지아입니다.
금일 {건물명} 정기 청소 진행 중 건물 유지관리에 참고하실 특이사항이 발견되어 안내해 드립니다.

[현장 특이사항]
- 위치: 3층 복도 센서등 (또는 1층 분리수거장)
- 내용: 3층 계단 센서등 전구가 수명을 다해 점등되지 않고 있습니다. (사진 첨부)
- 권장 조치: 야간 입주민 보행 안전을 위해 전구 교체가 필요해 보입니다. 
  (원하실 경우 다음 방문 시 실비로 규격 전구 준비하여 무상으로 교체 장착해 드릴 수 있습니다.)

건물의 작은 부분까지 세심하게 살피겠습니다. 편안한 하루 되세요!
```

## 2. 필수 4컷 사진 촬영 가이드 (무음 카메라 필수)

임대인이 보고서 사진을 보았을 때 가장 깨끗하다고 느끼는 **골든 앵글 4컷**입니다:

| 사진 순서 | 촬영 위치 | 촬영 포인트 | 좋은 예시 각도 |
|---|---|---|---|
| **1번 컷** | **1층 공동현관 로비** | 바깥이 투명하게 비치는 현관 유리문과 반짝이는 로비 바닥 | 밖에서 안으로, 또는 안에서 밖을 향해 허리 높이에서 촬영 |
| **2번 컷** | **계단실 전경 (3~4층)** | 위에서 아래 계단을 내려다보며 먼지 하나 없는 대리석 라인 | 계단 난간 손잡이와 바닥 모서리가 시원하게 보이도록 하향 촬영 |
| **3번 컷** | **우편함 및 창틀** | 우편함에 광고 전단지가 싹 정리되고 깨끗한 모습 | 정면에서 우편함 전체와 벽면이 단정하게 보이도록 촬영 |
| **4번 컷** | **1층 주차장 / 분리수거** | 바닥에 담배꽁초 없이 쓸려 있고, 재활용 마대가 정돈된 모습 | 주차장 전경과 분리수거대가 한눈에 들어오는 각도 |

> **주의사항**:
> 1. 입주민의 프라이버시(택배 상자의 이름/전화번호 송장, 특정 세대 현관문 번호)는 사진에 크게 노출되지 않도록 각도를 조절합니다.
> 2. 새벽 시간대이므로 계단 센서등이 켜진 상태에서 촬영하여 어둡지 않고 환하게 나오도록 합니다.

## 3. 현장 25분 셀프 체크리스트 (휴대용)

작업 누락을 방지하기 위해 스마트폰 화면에 띄우거나 코팅해 지참하는 순서표입니다.

```
 [ ] 1. 도착 (00:00) : 주차장 꽁초·낙엽 쓸기 & 분리수거대 봉투 묶기
 [ ] 2. 현관 (00:05) : 유리문 전용 세정제로 닦기 + 우편함 전단지 수거
 [ ] 3. 진입 (00:08) : 도어스토퍼 고정 후 최상층(5층) 직행
 [ ] 4. 포집 (00:10) : 대형 정전기 밀대로 5층->1층 계단 먼지 쓸어내리기
 [ ] 5. 닦기 (00:18) : 세정액 적신 극세사 패드로 5층->1층 바닥 훔치기
 [ ] 6. 터치 (00:23) : 극세사 손걸레로 난간 손잡이·창틀 훑기
 [ ] 7. 완료 (00:25) : 골든 4컷 사진 촬영 -> 카톡 보고 전송 -> 철수
```
