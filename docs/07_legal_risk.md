## 2. 숙박 청소 관련 (고객의 적법성 이슈)

우리가 숙박을 운영하는 것은 아니지만 **고객의 영업이 위법이면 우리 매출·평판에 영향**이 있습니다.

| 이슈 | 내용 | 우리 대응 |
|------|------|-----------|
| 외국인관광 도시민박업 | 거주 주택에서 외국인 관광객 대상, **오피스텔은 제외** [사실] | 온보딩에서 등록증·세이프스테이 조회 |
| 미등록 영업 | 강남 숙박 상당수가 미등록·샌드박스 특례 운영 [사실 경향] | 합법 우선 정책, 불가 시 장기 체류 상품만 |
| 단속·폐쇄 | 적발 시 호스트 영업 중단 → 우리 매출 손실 | 숙박 매출 비중 65% 이내 관리, 고객 분산 |
| 법령 변화 | 도시민박 거주 요건·내국인 대상 허용 범위 등 논의 지속 | **분기별 법령 모니터링** [확인필요] |
| 린넨 세탁 | 세탁업은 신고 대상, 자체 세탁 시 규제 가능 | **신고된 상업세탁소 외주** |
| 고객 개인정보 | 객실 사진·도어락 정보 | 개인정보보호법 준수 |

## 3. 서비스 대상별 유의사항

| 대상 | 유의 |
|------|------|
| **개인 가정 대상 청소**(예: 호스트가 아닌 일반 가정) | **가사근로자법**상 가정 가사서비스 제공기관 인증·규제 가능성 → 우리는 **사업장(공용부·오피스·숙소)** 중심으로 한정 [확인필요] |
| **빌라 공용부** | 집합건물법상 관리단 계약. 계약 주체(임대인 vs 관리단) 명확히, 세대 분담은 관리단 합의 서류 |
| **폐기물** | 분리수거 **정리**는 가능하나 대형·사업장 폐기물 수거·운반은 별도 허가 필요 → 계약서에 제외 명시 [확인필요] |
| **오피스** | 보안서약, 서류·장비 촬영 금지, 출입 로그. 야간 소음·진동 규정 |
| **외벽·고소** | 직접 시공 금지, 제휴 전문업체 활용 |

## 4. 노무

| 항목 | 내용 |
|------|------|
| 고용 형태 | 근로계약(정규·파트). **프리랜서·업무위탁은 근로자성 판단 리스크** → 초기부터 근로계약 중심 권장 [확인필요] |
| 최저임금 | 2027년 **10,700원** [사실]. 실제 시급 13,000원 설계 |
| 4대보험·산재 | 주 15시간 이상 등 요건 충족 시 4대보험, 산재는 근로자 전원 대상 |
| 주휴수당 | 주 15시간 이상·소정근로일 개근 시 발생 |
| 퇴직금 | 1년 이상 근속·주 15시간 이상 시 → 퇴직충당 월 인건비의 약 8.3% 반영 |
| 5인 이상 | **연장·야간·휴일 가산, 연차, 부당해고 제한** 등 전면 적용 → **Y1 중반 임계점** |
| 중대재해처벌법 | 5인 이상 50인 미만 사업장도 적용 (2024.1.27 시행) → **Y1 후반부터 안전관리체계 필요** [확인필요] |
| 야간 | 22~06시 야간 가산 → **06시 이후 시작** 설계 |
| 근로시간 | 유연 근무 가능하나 근로시간 기록 철저 (사진·시간 기록 활용) |

**노무 체크리스트**
- [ ] 표준 근로계약서·취업규칙(10인 이상 시 신고)
- [ ] 일용·단기 인력 신고(고용·산재 보험 신고)
- [ ] 안전교육 연 1회, 산재 대응 매뉴얼
- [ ] 외국인 채용 시 체류자격 확인

## 5. 세무

| 항목 | 내용 |
|------|------|
| 부가세 | 일반과세, 분기·반기 신고, 장비·차량(업무용) 매입세액 공제 |
| 소득세/법인세 | Y1 적자 → 이월결손금 활용, 청년창업 감면 검토 [확인필요] |
| 인건비 신고 | 원천세·지급명세서 |
| 현금영수증·세금계산서 | B2B는 세금계산서, 개인 호스트는 현금영수증/카드 |
| 업무용 차량 | 업무용 승용차 규정 확인 (승합·경형 밴 활용 시 유리한 경우 있음) [확인필요] |

> 개업 전 **세무사 1회 상담**(약 10~20만 원)으로 일반/간이, 청년감면, 법인 전환 시점을 확정하세요.

## 6. 보험

| 보험 | 목적 | 우선순위 |
|------|------|----------|
| **영업배상책임보험**(시설소유관리자/청소업) | 고객 재물 파손·분실, 대인 사고 | 필수 |
| **산재보험**(법정) | 근로자 업무상 재해 | 필수 |
| 4대 보험 | 법정 | 필수 |
| 화재·도난(장비·창고) | 자산 보호 | 권장 |
| 차량 보험(업무용) | 이동 중 사고 | 필수 |
| 사이버/개인정보 배상 | 데이터 사고 | 규모 커지면 |

**파손·분실 대응 절차**: 사고 즉시 사진 → 고객 통지 24시간 내 → 보험 접수 → 재발 방지 교육.
**보험료 가정**: 연 100~150만 원 [가정].

## 7. 계약서 필수 조항 (표준 계약 템플릿)

1. 서비스 범위·제외 항목(폐기물 수거·고소작업 등)
2. 방문 일정·시간대, 변경·취소 규정 (숙박은 긴급 취소 수수료)
3. 요금·정산일·연체 시 서비스 일시 중지
4. **연 1회 요금 조정 조항** (최저임금 인상률 연동)
5. 파손·분실 책임 범위, 보험 한도
6. 보안·개인정보 취급
7. 해지 조건(최소 1개월 사전 통보), 계약 갱신
8. 하자 보증(24시간 재청소)
