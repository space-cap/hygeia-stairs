## 2. 숫자를 읽는 법 (매우 중요)

이 계획의 **정량 수치는 대부분 "검증 전 가정"** 입니다. 표기 규칙은 다음과 같습니다.

| 표기 | 의미 |
|------|------|
| **[사실]** | 공공 자료·공시 등으로 확인된 수치 (출처 명시) |
| **[가정]** | 업계 일반론과 합리적 추론으로 둔 수치. **Phase 0 실사에서 반드시 검증** |
| **[확인필요]** | 법령·제도 등 시점에 따라 달라질 수 있어 전문가/관청 확인이 필요한 항목 |

> [!IMPORTANT]
> 시장 규모·단가·전환율은 **현장 실사 2주(Phase 0)** 로 교체해야 비로소 "계획"이 됩니다.
> 그 전까지는 "논리가 맞는 시나리오" 정도로 보세요. 검증 체크리스트는 [08 문서](08_roadmap_kpi.md)에 있습니다.

### 이 계획에 사용한 확정 사실
- **최저임금**: 2026년 10,320원, **2027년 10,700원(+3.7%)** — 고용노동부 고시 기준 (2027년 사업 시작 기준으로 비용 산정)
- **외국인관광 도시민박업**: 거주 주택 대상 합법 제도이며 **오피스텔은 제외**, 강남구청이 등록 현황을 공표 (세이프스테이로 합법 여부 조회 가능)
- **강남 공유오피스**: 강남구 내 100개 이상 지점이 선릉·역삼·삼성·대치에 걸쳐 밀집, 대형 브랜드는 한 역 반경에 다점포 전략

## 3. 브랜드 가칭

**하이지아 (Hygeia)** — 그리스 신화의 위생·건강의 여신.
저장소 이름 `hygeia-stairs`의 *stairs*는 두 가지 뜻으로 씁니다.
1. **계단(Stairs)** — 빌라 계단·공용부 청소에서 시작하는 첫걸음
2. **단계(Stairs)** — 대치동 → 반경 2km → 강남 → 확장으로 올라가는 **5단 성장 계단**
