# 28. 당근마켓 & 네이버 플레이스 즉시 등록용 실전 원고 패키지

> **"오늘 밤 스마트폰으로 복사해서 붙여넣기만 하면 대치동 지역 마케팅 즉시 개시"**  
> 당근마켓 비즈프로필, 첫 소식(피드) 이벤트 홍보글, 네이버 스마트플레이스 등록 정보, 카톡/문자 고객 응대 매크로 3종 완성본입니다.

## 1. 당근마켓 비즈프로필 세팅 원고

당근마켓 앱 > **'나의 당근'** > **'비즈프로필 만들기'** (비용: 0원)

### 1) 기본 정보 입력
- **상호명**: `하이지아 — 대치동 프리미엄 계단청소`
- **카테고리**: `청소/이사` > `건물/시설 청소`
- **활동 지역**: `대치4동` (이웃 동네: 대치1동, 대치2동, 역삼2동, 삼성2동 확장 선택)
- **대표 전화번호**: `010-XXXX-XXXX`
- **웹사이트 링크**: `https://hygeia-stairs.vercel.app`

### 2) 비즈프로필 소개글 (그대로 복사하여 붙여넣기)
```text

대치동에서 직접 거주하며 우리 동네 빌라와 상가 건물을 "내 집처럼" 책임지고 관리합니다.
```

## 2. 당근마켓 첫 게시글 (소식 피드) 등록 원고

비즈프로필 개설 후 **'소식 작성'** 버튼을 눌러 피드에 등록하는 첫 게시글입니다.

- **제목**: `[대치동 임대인 필독] 용역 알바 없는 프리미엄 계단청소, 1개 층 무료로 먼저 닦아드립니다!`
- **본문 원고**:
```text
대치동 빌라·상가 소유주 임대인분들, 안녕하십니까!
대치동 골목길 정기 계단관리를 대표가 직접 책임지는 [하이지아]입니다.

매달 청소비는 꼬박꼬박 나가는데...
• 계단 모서리에 묵은 먼지가 그대로 남아있나요?
• 신발 힐마크와 껌 자국이 지워지지 않나요?
• 청소업체가 오늘 다녀갔는지 알 길이 없어 답답하셨나요?

하이지아는 "대치동 주민인 대표"가 매주 직접 방문하여 장인 정신으로 관리합니다.

✨ [당근 이웃 한정 1개 층 무료 시범 이벤트] ✨
돈부터 내지 마세요! 
저희 작업 동선에 맞춰 임대인분 건물의 [1층 로비 + 계단 1개 층]을 비용 1원도 안 받고 무료로 반짝반짝 광택을 내드립니다.

직접 눈으로 청결도를 확인하시고, 마음에 드실 때 정기계약을 결정해 주세요. (마음에 안 드시면 그냥 끝내셔도 100% 무료!)

📌 무료 시범 신청 방법:
1. 아래 [채팅 문의] 클릭
2. 건물 위치(예: 대치4동 주민센터 인근) + 층수 + 연락처 남겨주시면 대표가 10분 내로 친절하게 일정 안내를 드립니다.

📞 대표 직통 상담: 010-XXXX-XXXX
🌐 공식 웹사이트: https://hygeia-stairs.vercel.app
```

## 3. 네이버 스마트플레이스 등록 정보

**네이버 스마트플레이스(https://smartplace.naver.com)** > **'신규 등록'** (비용: 0원)

### 1) 기본 정보
- **업체명**: `하이지아 대치본점 계단청소`
- **업종**: `청소대행` > `건물청소`
- **전화번호**: `010-XXXX-XXXX`
- **주소**: `서울특별시 강남구 대치동` (상세주소는 거주지 또는 대치동 일대 입력, 출장서비스 체크)
- **영업시간**: `매일 04:00 ~ 21:00 (상담 시간: 08:00 ~ 21:00)`

### 2) 대표 키워드 5개 (검색 노출 핵심)
1. `대치동계단청소`
2. `강남계단청소`
3. `대치동빌라청소`
4. `대치동정기청소`
5. `대치동건물관리`

### 3) 상세 설명글
```text
대치동 거주 대표 직접 관리 | 무소음 새벽 정기 케어 | 매회 카톡 4컷 전/후 사진 안심 보고 | 1억 원 영업배상책임보험 가입.

강남구 대치동(한티역, 선릉역, 대치사거리) 빌라, 다세대주택, 상가 정기 계단청소 전문 하이지아입니다. 
용역 알바를 쓰지 않고 대표가 직접 현장을 책임 관리하며, 모터 청소기를 쓰지 않는 0dB 무소음 극세사 흡착 방식으로 세입자 수면을 보장합니다.

현관 유리 손지문 제거, 전 층 대리석 계단 먼지 흡착, 계단 손잡이 에탄올 살균 소독, 필로티 주차장 담배꽁초 수거까지 철저하게 케어해 드립니다. 

[부담 없는 혜택] 1개 층 무료 시범 청소를 먼저 받아보시고 결정하세요!
문의: 010-XXXX-XXXX
공식 웹사이트: https://hygeia-stairs.vercel.app
```

## 4. 카톡 & 문자 고객 응대 매크로 3종 (복사해서 즉시 전송)

```text

소중한 건물 관리 문의를 남겨주셔서 진심으로 감사드립니다.

문의하신 건물의 위치와 대략적인 층수(예: 4층 빌라, 엘리베이터 유무)를 알려주시면 정확한 표준 단가와 맞춤 관리 방식을 5분 안에 안내해 드리겠습니다.

• 대표 직통: 010-XXXX-XXXX
• 공식 사이트: https://hygeia-stairs.vercel.app
```

### ② 견적 및 1개 층 무료 시범 제안 문자
```text
[하이지아 정기관리 견적 안내]
사장님, 요청하신 건물 관리 견적 안내드립니다.

• 대상 건물: 대치동 OOO 빌라 (4층 기준)
• 방문 주기: 주 1회 정기 방문 (월 4회)
• 정기 관리비: 월 70,000원 (VAT 별도)
• 관리 범위: 1층 공동현관 유리 광택, 전 층 계단 극세사 무소음 청소, 난간 손잡이 무취 살균, 주차장 꽁초 수거, 매회 완료 카톡 4컷 사진 전송

다음 주 O요일에 [1층 로비 + 계단 1개 층]을 비용 1원도 안 받고 무료로 싹 닦아드릴 테니 상태만 먼저 눈으로 확인해 보세요.
무료 시범 진행을 원하시면 편하게 "시범 신청"이라고 답장 남겨주세요!
```
