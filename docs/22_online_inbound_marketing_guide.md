# 22. 0원 무자본 온라인 인바운드 마케팅 가이드 (당근마켓 & 네이버 플레이스)

> **"발로 뛰는 전단지와 함께, 가만히 있어도 건물주에게서 전화가 오게 만드는 법"**  
> 광고비 0원으로 대치동·도곡동·역삼동 건물주의 정기관리 문의를 끌어당기는 당근마켓 비즈프로필, 네이버 지도(스마트플레이스), 카카오톡 채널 10분 무료 세팅 매뉴얼입니다.

---

## 1. 왜 대치동에서 '당근마켓'과 '네이버 지도'인가?

많은 청소업체가 수십만 원의 네이버 파워링크 광고비를 날리지만, **로컬 계단청소의 진짜 건물주(50~70대)는 당근마켓과 네이버 지도를 봅니다.**

```
[대치동 건물주의 검색 행동 패턴]
1. 당근마켓 동네생활 탭에서 "대치동 빌라 계단청소 잘하는 곳 있나요?" 검색
2. 네이버 지도에서 "대치동 계단청소"를 검색하여 동네 가까운 업체 확인
3. "대치동 주민 대표가 직접 청소하고 매회 카톡 사진을 보내준다"는 문구에 신뢰를 느끼고 전화 통화
```

---

## 2. 당근마켓 비즈프로필 10분 세팅법 (로컬 최강 무기)

당근마켓 비즈프로필은 개설 및 운영 비용이 **100% 무료**입니다.

### 1) 기본 정보 등록
- **프로필명**: **하이지아 계단청소 (대치본점)**
- **카테고리**: `생활/편의` → `청소/이사`
- **지역 설정**: **대치4동** (반경 3km 내 대치1·2동, 도곡1·2동, 역삼1·2동 자동 노출)
- **대표 사진**: 깔끔하게 닦인 반짝이는 대리석 계단 사진 또는 장비 사진.

### 2) 소개글 표준 원고 (그대로 복사해서 사용)

```
[대치동 주민 대표가 매주 직접 쓸고 닦는 정기 계단관리, 하이지아입니다!]

안녕하세요! 대치동 주민 여러분, 
빌라·원룸·상가 공용부 정기청소 전문 [하이지아(Hygeia)] 대표입니다.

"기존 청소업체가 5분 만에 대충 물걸레질만 하고 가서 불만이셨나요?"
"새벽에 시끄럽게 청소기를 돌려 세입자 민원이 들어오셨나요?"

하이지아는 다른 용역 알바를 쓰지 않고, 
대치동에 거주하는 대표인 제가 매주 직접 꼼꼼하게 관리합니다!

★ 하이지아만의 3대 안심 약속:
1. [소음 0dB 무소음 청소] - 새벽에도 세입자 수면 방해 없는 극세사 케어
2. [카톡 안심 사진 보고] - 매회 청소 직후 4컷 전/후 사진 즉시 전송
3. [1억 배상책임보험 가입] - 시설물 파손 및 안전사고 100% 책임 보증

■ 관리 범위: 현관유리, 전 층 계단, 손잡이 살균 소독, 1층 주차장 꽁초 수거
■ 정기 관리비: 4층 빌라 기준 월 70,000원부터 (회당 17,500원꼴)

🎁 [당근 단골 혜택] 
첫 달 계약 시 "계단 묵은 때 딥클린 무상 시범"을 무료로 제공해 드립니다!
채팅이나 전화로 편하게 문의주세요. (대치동 관내 10분 내 방문 견적 가능)

☎ 직통 문의: 010-XXXX-XXXX
```

### 3) 당근마켓 키워드 알림 설정 (핵심 꿀팁)
당근마켓 앱 → `나의 당근` → `키워드 알림`에 아래 키워드를 등록해 둡니다:
- **`계단청소`**, **`빌라청소`**, **`건물관리`**, **`청소업체`**, **`정기청소`**
- **효과**: 대치동/도곡동 주민이 *"계단청소 업체 추천해주세요"*라는 글을 올리는 즉시 스마트폰 알림이 뜹니다. 5분 안에 정중하고 친절한 댓글을 달면 80% 이상 계약으로 이어집니다.

## 3. 네이버 스마트플레이스(지도) 10분 무료 등록

네이버 지도에 등록해 두면, 대치동 건물주가 네이버에서 **"대치동 계단청소"**를 검색했을 때 대표님의 전화번호와 위치가 지도 최상단에 뜹니다.

### 1) 등록 절차
1. 네이버 검색창에 **`네이버 스마트플레이스`** 검색 후 접속 (smartplace.naver.com).
2. [신규 등록] 클릭 → 상호명: **`하이지아 청소관리 대치본점`** 입력.
3. 사업자등록번호 입력 및 주소(대치동 자택 주소) 입력.
4. 업종 선택: **`청소대행`** 또는 **`건물관리대행`**.

### 2) 필수 검색 키워드 5개 등록
- **대치동계단청소**, **대치동빌라청소**, **강남계단청소**, **빌라정기청소**, **원룸건물관리**

### 3) 메뉴 및 가격표 투명 등록 (신뢰도 상승)
- 빌라 4층 주1회 정기관리: **월 70,000원**
- 빌라 5층 주1회 정기관리: **월 80,000원**
- 상가주택/오피스 주2회 정기관리: **월 150,000원**
- 방문 견적 및 1개 층 시범청소: **0원 (무료)**

## 4. 카카오톡 비즈니스 채널 개설 (프로페셔널 보고용)

개인 카카오톡 계정으로 사진을 보내는 것보다, **`하이지아 건물관리`**라는 카카오톡 채널을 만들어 보고서를 보내면 임대인이 느끼는 신뢰도가 대기업 수준으로 올라갑니다.

1. 카카오톡 채널 관리자센터(center-pf.kakao.com) 접속 (스마트폰 앱 가능).
2. 무료 채널 개설:
   - 채널 이름: **`하이지아 건물관리 대치본점`**
   - 검색용 아이디: **`hygeia_clean`**
   - 프로필 사진: 하이지아 로고 또는 깔끔한 청소 완료 사진
3. 활용법: 매회 청소 후 [14번 카톡 보고서](../docs/14_inspection_checklist_and_report.md) 사진 4장을 이 채널을 통해 임대인에게 전송.

## 5. 온라인 문의 인바운드 접수 시 3단계 대응 공식

당근마켓 채팅이나 네이버 지도를 보고 전화가 걸려왔을 때의 대응 공식입니다:

```
[1단계] 친절한 동네 주민 인사
"감사합니다! 대치동 거주 대표가 직접 관리하는 하이지아 청소입니다."

[2단계] 층수/위치 확인 후 즉시 기준 견적 제시
"대치4동 4층 빌라시군요! 주 1회 기준 월 7만 원입니다."

[3단계] 당일 현장 방문 무료 시범 클로징
"제가 바로 대치동에 있으니, 오늘 오후에 지나가는 길에 1개 층만 무료로 닦아서 보여드리겠습니다. 
계약은 깨끗해진 것 직접 눈으로 보시고 결정하세요!"
```
